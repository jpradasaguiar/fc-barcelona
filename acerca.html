Acerca de este sitio

¿Quién soy?

Hola, soy Jorge Pradas Aguiar, creador de este sitio web dedicado al FC Barcelona y a su apasionante historia en la Champions League. Este proyecto nació como una forma de practicar desarrollo web mientras comparto mi pasión por el fútbol.

¿Qué encontrarás aquí?

En este sitio podrás leer crónicas de partidos, conocer a algunos de los jugadores más destacados del primer equipo y repasar la historia y la rivalidad entre el FC Barcelona y el Paris Saint-Germain. Todo con un diseño limpio, responsive y pensado para que la lectura sea cómoda desde cualquier dispositivo.

Tecnologías utilizadas

El sitio está construido con HTML5 y CSS3, sin frameworks externos, y publicado de forma gratuita mediante GitHub Pages. El código es sencillo y fácil de mantener, ideal para seguir ampliándolo con nuevas secciones.

Contacto

Si quieres ponerte en contacto conmigo para sugerencias, correcciones o simplemente para hablar de fútbol, puedes hacerlo a través de la página de Contacto.
